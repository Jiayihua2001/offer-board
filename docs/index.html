    Screened out, and why

      How the numbers work

      Your offer line starts at $300K a year (set in config.yaml), an estimate for Amazon Applied Scientist II (L5), where PhD new grads usually land. Levels.fyi puts the US L5 average near $308K (base about $166K, stock $108K, bonus $34K), and Blind posters quote an L5 band of roughly $318K–$419K. Some PhD hires are leveled L4, around $241K–$260K.

      Each bar estimates year-1 total pay at the PhD new-grad level: the posted base where there is one, plus that employer’s usual bonus and equity. The dot marks the midpoint. Above means the midpoint is at least 10% over your line, near means 85–110%, and anything lower is hidden. Startup equity is counted at paper value, so discount it.

      Visa checks

      Every role is in the US. Each row shows whether the employer sponsors H-1B visas, based on its public Department of Labor filings or the posting itself. Rows tagged “Ask about visa” have a thin record, so ask before you invest time.

      Four questions for every recruiter: Will you register me in the March 2027 H-1B lottery, and at what wage level? Are you enrolled in E-Verify, which STEM OPT requires? Do you file O-1 petitions for PhD hires? Would you still file if DHS finalizes its proposed fee on cap-subject H-1B petitions?

      Where these came from

      • Applicant-tracking APIs (Greenhouse, Lever, Ashby, Workday) for the companies listed in config.yaml.
      • Google’s careers search and NVIDIA’s Workday search.
      • The speedyapply and Simplify new-grad trackers on GitHub.
      • Claude web searches on a rotating set of queries.
      • Pay data: posted ranges, Levels.fyi and Blind. Visa data: Department of Labor H-1B filings.

      Keeping it current

      A GitHub Action can run twice a day once the repository has an API key. It polls company job boards and the GitHub new-grad trackers, runs Claude web searches, screens every new posting against your offer line, location and visa needs, re-checks each link and drops closed roles. Without the key, open a Claude Code session on the repo and ask for a sweep: it runs the same sources and screens the backlog in parallel.
